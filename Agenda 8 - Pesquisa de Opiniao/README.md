# Pesquisa de Opinião - Grau de satisfação no atendimento

Este projeto em Python foi criado para praticar o ciclo **Entrada → Processamento → Saída**. 
<br>

O programa solicita do usuário seu **nome**, **nome** e **opinião do entrevistado sobre o atendimento prestado** devendo retornar a quantidade de respostas **“EXCELENTE”** e **“RUIM”**:
<br>

## Condições dadas:
1. Desenvolver um programa em Python utilizando a estrutura de repetição para coletar e exibir o retorno de uma pesquisa de atendimento ao cliente.
2. O programa deve solicitar a digitação do nome, idade e opinião do entrevistado sobre o atendimento prestado, sendo: <br>
1 - EXCELENTE <br>
2 - BOM <br>
3 - RUIM <br>
3. A pesquisa deve ser feita com 50 entrevistados.
4. Realizar testes com 10 entrevistados para validar o funcionamento do programa
